# Glowy Clinic & Beauty

نظام إدارة داخلي لمركز **Glowy**.

النسبة تُحسب من المبلغ المحصّل فعليًا، وليس من قيمة الحجز.

## التشغيل

```bash
cd C:\Users\104750\Desktop\glowy
npm install
npx prisma db push
npx tsx prisma/seed.ts
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

## حسابات التجريب

كلمة المرور لجميع الحسابات: `123456`

| الدخول | الدور |
| --- | --- |
| admin | مدير |
| reception | استقبال |
| sara | خبيرة مكياج |
| noor | خبيرة مكياج |
| reem | خبيرة شعر |

غيّري كلمات المرور قبل الاستخدام الفعلي.

## ملاحظات

- البيانات محفوظة محليًا في SQLite (`prisma/dev.db`) حتى يعمل النظام بدون تثبيت PostgreSQL.
- ساعات العمل الافتراضية من 9:00 إلى 21:00 بتوقيت طرابلس.
- مدة الخدمة قابلة للضبط، وتُستخدم لمنع تعارض مواعيد الخبيرة.
